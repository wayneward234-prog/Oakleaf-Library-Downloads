# Oakleaf Library — Public Android Version History

This public page lists the **published Android APK releases** for Oakleaf Library,
newest version first. Entries reproduce the release notes supplied when each
APK was published; they are **not independent verification** of every claim.

The application source, development details, private catalogue information
and signing material are **not published here**.

Download the [latest Android APK](https://github.com/wayneward234-prog/Oakleaf-Library-Downloads/releases/latest/download/Oakleaf-Library.apk).

## Version 2.0.4 — 12 November 2026

[View this GitHub release](https://github.com/wayneward234-prog/Oakleaf-Library-Downloads/releases/tag/android-2.0.4)

Install this APK over Oakleaf 2.0.3 to keep your existing library. You can also open the installed app and accept its update prompt.

This update adds precise book placement with gaps, clears the cabinet top, and fixes horizontal spine photographs and books disappearing when they return to the cabinet. Both APK downloads contain the same signed app.

## Version 2.0.1 — 11 November 2026

[View this GitHub release](https://github.com/wayneward234-prog/Oakleaf-Library-Downloads/releases/tag/android-2.0.1)

Oakleaf Library 2.0.1 for Android

Optional photograph-assisted book entry and natural-language library search are prepared for later activation. AI is off by default; normal offline/manual use remains available.

Download Oakleaf-Library.apk below and open it on your Android phone. This build retains the existing app package and signing identity for an in-place update.

AI activation requires separately configured private hosting and API access. No API credentials are included in this APK.

Verified locally: both builds, 56 Android unit tests, 12 gateway tests, isolated emulator AI/camera/gallery/bookcase/zoom/backup flows. AI tests use simulated responses; live AI accuracy and physical-phone behaviour remain unverified.
